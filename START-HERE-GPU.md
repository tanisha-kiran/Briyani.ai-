# Start the current version

The current application uses the local Qwen3.5 4B model, not the older supplied `biryani-planner` model. Read [README.md](README.md) for setup and current limitations.

On this laptop: open START-STUDIO.cmd, then http://127.0.0.1:53841/.

For a new laptop: SETUP-WINDOWS.cmd, SETUP-LOCAL-MODELS.cmd, then START-STUDIO.cmd. The setup downloads models; all generation runs locally afterward. Do not run model downloads during an offline demo.
